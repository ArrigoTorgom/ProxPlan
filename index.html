Import Calendar
Import events from one or more .ics files (exported or saved from Outlook, Google Calendar, or Apple Calendar) as meetings on your Planner. You can also drag .ics files onto any page, or copy an invite file and press Ctrl+V. A preview lets you choose what to import and assign projects. Repeating meetings are expanded for the next 12 months, time zones are converted to yours, and cancellations remove the meeting. Re-importing updates matching events instead of duplicating them.

Desktop App
Install Planner as an app on this computer. It opens in its own window, can be pinned to your taskbar, and keeps working without an internet connection. It uses the same data you see in the browser, so nothing needs to be moved.
Working Hours
Set the hours you work. They give Log Time its default hours, set how much work fits in a day on the To Do tab (meeting time is taken off), and are used for the hours booked when you log leave. Add breaks such as lunch, and use the tick box at the bottom if some days differ.
Leave
Leave and public holidays are booked to a single Leave project in your timesheet, so those days are never left blank.
